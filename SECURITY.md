# Security Policy

## Reporting a vulnerability

We take security vulnerabilities seriously. Please **do not** open a public GitHub issue for security problems.

Report vulnerabilities via one of these private channels:

1. **GitHub Security Advisory (preferred)**: open a private security advisory on the affected repository —
   `Security` tab → `Report a vulnerability`, or visit
   `https://github.com/Xero-Team/<repo>/security/advisories/new`.
2. **Email**: `thefoolyuzhe@gmail.com` with the subject `[SECURITY] <repo>: <short summary>`.

Please include:
- Affected repository and version / commit
- A description of the vulnerability and its impact
- Reproduction steps or proof of concept
- Suggested fix (optional)

## Response timeline

We will acknowledge your report within **72 hours** and aim to provide a fix or mitigation within **14 days**, depending on severity and complexity.

## Scope

This policy applies to all repositories under the **Xero-Team** organization. Archived repositories (`*-OLD` / `*-old`) are out of scope.
