<h3 align="center">Xero-Team</h3>

<p align="center">
  A small R&D collective focused on three things —<br>
  a programming-language compiler, AI agent frameworks, and a pure-Rust PDF parser.
</p>

---

## Focus areas

- **zerolang** — a programming language & its compiler ([CZC](https://github.com/Xero-Team/CZC) · [testcases](https://github.com/Xero-Team/Zero-Lang-Testcases) · [VS Code highlight](https://github.com/Xero-Team/Zero-Lang-Highlight-Vsix))
- **AstrBot & AI** — agent frameworks and tooling ([AstrBot](https://github.com/Xero-Team/AstrBot) · [plugins](https://github.com/Xero-Team/astrbot_plugin_image_generation) · [codexmcp](https://github.com/Xero-Team/codexmcp) · [hermes-agent](https://github.com/Xero-Team/hermes-agent))
- **zpdf** — PDF parsing in pure Rust ([zpdf](https://github.com/Xero-Team/zpdf) · [skill](https://github.com/Xero-Team/zpdf-skill))

The organization also hosts research and reference repositories — not enumerated here.
